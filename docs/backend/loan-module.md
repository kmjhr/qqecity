# 轻创业智能授信模块（模块2）需求

本文档对应场景二 · 城市轻创业（创业赋能）。

## 功能清单

| # | 功能点 | 角色+页面+操作 | 优先级/Sprint | 可追溯 |
| --- | --- | --- | --- | --- |
| L-1 | B 类免费预审（创业计划+人群资质准入，**不查征信**、给出额度区间）【模拟】 | 青年创业者在"贷款预审页"提交创业计划与人群资质，获取 1—2 万元额度区间 | P0 / S3 | 说明书 5.4、7.3 |
| L-2 | A/B 双轨授信展示（A 类最高5万循环额度、B 类小额定向）【模拟】 | 青年创业者在"授信页"查看本人 A/B 类型与额度 | P0 / S3 | 说明书 5.4、7.3 |
| L-3 | 受托支付模拟（100% 定向打给指定商户，资金不经过个人账户）【模拟】 | 青年创业者在"提款页"选择真实交易并指定收款商户，系统模拟受托支付并展示流水 | P0 / S3 | 说明书 5.4、7.3 |
| L-4 | 随借随还循环额度（按实际用款计息、归还后额度恢复）【模拟】 | 青年创业者在"额度页"查看可用额度与还款记录 | P1 / S6 | 说明书 5.4 |
| L-5 | 创业信用画像（流水聚合建模）【占位】 | 运营/青年用户在"画像页"查看经营画像标签 | P2 / S7 | 说明书 5.4、6 |
| L-6 | 创业贴息政策推送【占位】 | 青年创业者在"贷款页"查看匹配的贴息政策入口 | P2 / 后置 | 说明书 5.4 |

## 说明

- B 类预审不查征信，基于创业计划与人群资质给出 1—2 万元额度区间（服务层规则模拟）
- A 类最高 5 万循环额度、B 类小额定向
- 受托支付 100% 定向打给指定商户，资金不经过个人账户（模拟）
- 商户列表为预置数据，受托支付定向打款目标
