# 后端接口规范

本文档汇总系统前后端接口契约，包括统一返回格式、错误码定义、鉴权方式等。内容来源于技术选型明细、AI 开发计划与需求清单中的接口约定。

## 一、统一返回格式

所有接口返回统一的 JSON 结构：

```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 业务状态码，0 表示成功，非 0 表示异常 |
| message | string | 状态描述，成功为 "success"，失败为错误信息 |
| data | object/array/null | 业务数据，成功时返回，失败时可为 null |

## 二、错误码定义

错误码与设计说明书 8.2 节一致：

| 错误码 | 含义 | 典型场景 |
| --- | --- | --- |
| 0 | 成功 | 接口正常返回 |
| 1001 | 参数错误 | 请求参数缺失、格式不正确、校验失败 |
| 1002 | 业务异常 | 业务规则不满足（如重复注册、状态非法） |
| 2001 | 未登录 / Token 无效 | 无 Token、Token 伪造、Token 过期 |
| 2002 | 无权限 | 越权访问他人数据、角色权限不足 |
| 3001 | 资源不存在 | 查询的记录不存在、路径错误 |
| 3002 | 资源冲突 | 唯一键冲突、重复提交 |
| 4001 | 第三方服务异常 | 模拟桩失败、外部依赖不可用 |
| 5000 | 系统内部错误 | 未捕获异常、服务器内部错误 |

## 三、鉴权方式

采用 JWT（JSON Web Token）无状态鉴权。

**请求头**：
```
Authorization: Bearer <JWT>
```

**免登录接口**：
- 路径前缀：`/api/v1/auth/**`
- 包含：注册、登录等无需鉴权的接口

**鉴权规则**：
- 携带有效 Token → 正常执行业务逻辑
- 无 Token 或 Token 无效/过期 → 返回 `2001` 错误码
- 越权访问他人数据 → 返回 `2002` 错误码

## 四、接口路径规范

- 统一前缀：`/api/v1`
- 模块路径：`/api/v1/{模块名}/{功能}`
- 示例：
  - `/api/v1/auth/register` — 用户注册
  - `/api/v1/auth/login` — 用户登录
  - `/api/v1/auth/me` — 当前用户信息
  - `/api/v1/guarantee/...` — 安居保函模块
  - `/api/v1/loan/...` — 青创e贷模块
  - `/api/v1/budget/...` — 预算消费模块
  - `/api/v1/safety/...` — 金融安全模块
  - `/api/v1/message/...` — 消息中心模块

## 五、前后端联调约定

- **开发环境**：Vite 将 `/api` 代理至后端 8080 端口（可通过 `VITE_API_TARGET` 环境变量调整）
- **生产环境**：由 Nginx 反向代理，`/api` 前缀转发至后端服务
- 前端 Axios 封装：自动注入 Token、统一错误提示、遇到 2001 自动登出并跳转登录页
