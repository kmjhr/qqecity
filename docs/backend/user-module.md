# 用户模块需求

本文档从需求清单中提取用户注册登录相关的功能需求（P-1 至 P-3）。

## 功能清单

| # | 功能点 | 角色+页面+操作 | 优先级/Sprint | 可追溯 |
| --- | --- | --- | --- | --- |
| P-1 | 用户注册（含人群资质字段：在校生/毕业2年内等） | 青年用户在"登录/注册页"填写手机号、姓名、证件号、人群类型提交注册 | P0 / S1 | 说明书 2.1、5.2 |
| P-2 | 用户登录（手机号+密码，签发 JWT） | 青年用户在"登录页"输入手机号密码登录，进入首页 | P0 / S1 | 说明书 2.1、8.3 |
| P-3 | 当前用户信息与退出 | 青年用户在"首页/个人中心"查看本人信息、退出登录 | P0 / S1 | 说明书 5.2 |

## 相关说明

- 用户人群类型用于资质准入判断（如应届毕业生、青年创业者等），与各业务模块的准入规则关联
- 登录成功后签发 JWT，前端存储并在后续请求中通过 `Authorization: Bearer <JWT>` 携带
- 密码采用 SHA-256 散列存储（演示系统），正式化须替换为 BCrypt 等加盐算法
- 演示账号（用户名登录）：`admin / 123456`
