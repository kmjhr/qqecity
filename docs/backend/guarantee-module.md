# 安居金融风控模块（模块1）需求

本文档对应场景一 · 青年入城安居（就业护航）。

## 功能清单

| # | 功能点 | 角色+页面+操作 | 优先级/Sprint | 可追溯 |
| --- | --- | --- | --- | --- |
| G-1 | 保函申请（录入房东信息、租赁要素、押金金额，上传租赁合同与房屋照片）【模拟】 | 青年租客在"保函申请页"填写表单并上传材料，提交申请 | P0 / S2 | 说明书 5.3、7.1 |
| G-2 | 房东在线确认与电子签署 | 房东（演示账号）在"保函确认页"核验信息、确认条款并签署 | P0 / S2 | 说明书 5.3、7.1 |
| G-3 | AI 合同复审（识别租金贷/霸王条款/押金异常/租期矛盾；低风险自动通过，存疑转人工）【模拟】 | 系统在"复审环节"按规则评分，命中风险词转人工（演示自动通过并标注） | P0 / S2 | 说明书 5.3、7.2 |
| G-4 | 保函缴费与电子开函【模拟】 | 青年租客在"保函详情页"缴纳保函费（演示费率 0.8%—1.5%），系统开立电子保函并推送房东 | P0 / S2 | 说明书 5.3、7.1 |
| G-5 | 保函查询与状态流转（申请中→待确认→待缴费→已开立→已失效） | 青年租客在"保函列表/详情页"查看状态流转 | P0 / S2 | 说明书 5.3、6 |
| G-6 | 违约索赔（提交证据→AI初审→人工复核→申辩期）【模拟】 | 房东在"索赔页"提交违约证据，系统记录证据、展示初审结果（演示自动通过） | P1 / S6 | 说明书 5.3、7.1 |
| G-7 | 人才安居政策智能匹配【占位】 | 青年用户在"保函页"查看匹配的安居政策条目 | P2 / 后置 | 说明书 5.3 |

## 状态流转

```
申请中 → 待确认 → 待缴费 → 已开立 → 已失效
```

## 说明

- 保函申请、复审、开函等银行能力均由服务层规则模拟
- AI 合同复审基于关键词规则判定（租金贷/霸王条款/押金异常/租期矛盾），命中风险词转人工复核
- 演示中人工复核自动通过并标注
- 保函费率演示值为 0.8%—1.5%
