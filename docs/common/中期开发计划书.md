## 一、项目背景与目标

### 1.1 项目简介

《青启e城》是面向青年的金融智能服务平台演示系统，覆盖**三大场景**（安居、轻创业、碎片消费）与**五大模块**（安居金融风控、轻创业智能授信、创业经营赋能、碎片消费治理、青年金融安全），对应需求文档 G / L / B / C / S 编号。技术栈：Spring Boot 3 + MyBatis-Plus + MySQL 8 + Redis + JWT 单后端，Vue3 双前端（user-web JS 版 / admin-web TS 版），Docker Compose 一键部署。

### 1.2 现状盘点（初期已完成，中期从这里起步）

| 类别 | 状态 | 说明 |
| --- | --- | --- |
| 需求清单 | ✅ 完成 | `docs/common/requirements.md`，五大模块 P0/P1/P2 逐条可追溯 |
| 原型设计 | ✅ 完成 | `prototype/` 可点击静态原型 |
| 数据库设计 | ✅ 完成 | `backend/sql/schema.sql` 25 张表 + `docs/deployment/database-design.md` |
| 部署体系 | ✅ 完成 | Docker Compose + Windows/Linux 脚本 + 10 篇部署文档 |
| 后端 user 模块 | ✅ 完成 | 注册（含人群资质）/登录/刷新/登出/JWT 双令牌 + Redis 黑名单降级 |
| 后端 message 模块 | ✅ 完成 | 消息列表/已读/全部已读/未读数量 |
| 后端 5 大业务模块 | 🟡 占位 | guarantee / loan / bookkeeping / budget / safety 仅占位 Controller 返回模拟数据 |
| 用户前端 | 🟡 骨架 | 10 个页面骨架（5 模块占位页 + 登录/注册/首页/消息/个人中心） |
| 管理前端 | 🟡 骨架 | 仅 login / dashboard / system 3 页 |

### 1.3 中期目标

1. 后端：保函、贷款、预算、安全、记账 5 模块补齐 Entity+Mapper+Service+Controller，对接已有 25 张表，业务规则按【模拟】口径实现。
2. 前端：用户端 5 个占位页改调真实接口；管理端保证登录与仪表盘可用。
3. 主链路：requirements.md 的 **14 步演示主链路**逐环节可点通（见 §四 验收基线）。
4. 工程规范：统一返回、错误码、JWT 鉴权、Swagger 注解、模拟数据标注"模拟"。

### 1.4 本期不做清单（中期明确排除）

1. 微信小程序端（与 requirements.md 边界 §7 一致）。
2. P2 功能：保险代销、财税科普/个转企、征信健康管理、贴息政策推送、信用画像建模。
3. 防刷单三道防线完整实现、RAG 对话引擎、数据中台画像。
4. 公网部署与运维（进入终期且具备服务器后再做）。
5. 真实银行对接（征信/放款/保函开立全部模拟桩）。

## 四、测试与验收

```

④ 缴费出函 → ⑤ 查询保函（状态=已开立）→ ⑥ B 类免费预审（额度区间，无征信查询）→

⑩ 分级提醒（50%→20%→超支）→ ⑪ 结余转储蓄 → ⑫ 输入"征信修复"话术被拦截 →
⑬ 消息中心收到对应提醒
```
