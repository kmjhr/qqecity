## 二、情景内容创作（L3 对话演练剧本，自由创作 + 官方口径）

四个情景覆盖：刷单返利 / 冒充公检法 / 虚假征信（注销贷款账户）/ AI 换脸冒充熟人。每个情景含 **背景、诈骗分子 4–6 轮话术、用户应对判定**。

> 话术与套路来源：公安部、最高检、央视、央广、人民公安报、新华网等公开反诈口径（见文末来源清单），情节为演示创作，均标注「模拟教学」。

### 情景 A：刷单返利（兼职引流 → 小额返利 → 收割）

**背景**：你是大三学生，课少想兼职。微信群有人发「动动手指、日赚三百」的兼职广告，你加了 "客服"，对方让你先做两个点赞任务，马上收到了 8 元、15 元返利。现在对方让你下载一款 App 做 "垫资任务"。



| 轮次 | 诈骗分子话术（模拟）                          | 用户可选应对                                                    | 判定                     |
| -- | ----------------------------------- | --------------------------------------------------------- | ---------------------- |
| 1  | 「下载这个 App，注册后做 ' 购物垫付 ' 任务，一单返 20%」 | A. 下载并按提示垫付 200 元试单　B. 拒绝垫资，要求走正规招聘渠道　C. 先问 "为什么不在群里直接结算" | B→安全 +30；A→危险 +40；C→中性 |
| 2  | 「你刚才操作失误卡单了，系统要冻结，需再充 800 元解冻」      | A. 转账 800 元解冻　B. 挂断并拨打 96110 核实　C. 问 "解冻金能不能从佣金里扣"        | B→安全 +40；A→危险 +30      |
| 3  | 「解冻后本金佣金一起返，最后一步了，别半途而废」            | A. 再充 2000 元 "最后一单"　B. 立即报警并截图留证　C. 犹豫，让对方先退已垫资金          | B→安全 +30；A→危险 +30      |

**判定基准**：任何 "垫资 + 要求继续充值" 都命中危险词库（垫资 / 解冻 / 保证金 / 卡单）；"96110 / 报警 / 拒绝垫资 / 不下载陌生 App" 命中识破词库。

### 情景 B：冒充公检法（精准报信息 → 伪造文书 → 安全账户）

**背景**：你接到一个来电显示 "96110" 的电话，对方自称市反诈中心民警，准确报出你的姓名和身份证号，说你名下手机卡发了 300 余条诈骗短信、涉嫌一起洗钱案，要求你 "配合调查、全程保密"，并通过聊天软件发来一张带公章的 "逮捕令"。



| 轮次 | 诈骗分子话术（模拟）                                | 用户可选应对                                                     | 判定                         |
| -- | ----------------------------------------- | ---------------------------------------------------------- | -------------------------- |
| 1  | 「案件涉密，绝对不许挂电话、不许告诉任何人，否则立即上门拘捕」           | A. 挂断电话，拨打 110 反查核实　B. 按要求保持通话、清空手机　C. 问对方警号并说 "我去派出所当面配合" | A→安全 +40；C→中性 +10；B→危险 +30 |
| 2  | 「下载这个 ' 安全防护 'App 开启屏幕共享，我们对你的资金做清查」      | A. 拒绝安装任何屏幕共享软件　B. 安装并按提示登录手机银行　C. 问 "清查为什么要看我的银行密码"       | A→安全 +30；C→中性 +10；B→危险 +40 |
| 3  | 「清查显示你的账户有涉案资金，必须转到 ' 安全账户 ' 验资，24 小时后返还」 | A. 立即挂断并拨打 96110 报警　B. 转账至对方指定账户 "自证清白"　C. 到就近派出所核实        | A/C→安全 +40；B→危险 +40        |

**判定基准**：命中 "安全账户 / 共享屏幕 / 验证码 / 转账"= 危险；"挂断 / 110/96110 / 当面核实 / 公检法不会网上办案"= 识破。识别要点：公检法机关没有 "安全账户"，不会通过电话 / 社交软件办案。

### 情景 C：虚假征信・注销贷款账户（冒充平台客服 → 影响征信施压 → 清空额度）

**背景**：你接到自称 "某金融平台客服" 的电话，说你大学期间注册过一个贷款账户，现在国家政策要求注销，不注销会影响征信、影响以后买房买车，对方还准确说出你的学校和姓名。



| 轮次 | 诈骗分子话术（模拟）                                   | 用户可选应对                                                                      | 判定                         |
| -- | -------------------------------------------- | --------------------------------------------------------------------------- | -------------------------- |
| 1  | 「你名下有个校园贷账户没注销，征信马上要出不良记录了」                  | A. 挂断，去征信中心官网 / 银行 App 自查征信　B. 按对方指引操作注销　C. 问 "我在哪家平台注册的？我从未办过校园贷"          | A→安全 +40；C→中性；B→危险 +30     |
| 2  | 「需要把平台上的贷款额度全部提出来转到我方 ' 清算账户 ' 验资，验完返还并注销账户」 | A. 拒绝 —— 征信修复 / 注销不需要转账，官方渠道免费　B. 按要求借款并转账 "清空额度"　C. 让对方出示官方红头文件并致电平台官方客服核实 | A→安全 +40；C→中性 +10；B→危险 +40 |
| 3  | 「再不下架你的额度，就要收每月 3000 元违约金并拉黑征信」              | A. 直接挂断，拨打 96110　B. 转账 "违约金" 息事宁人　C. 向平台官方客服电话核实真伪                          | A/C→安全 +40；B→危险 +40        |

**判定基准**：个人征信异议处理 / 注销账户**免费、无任何转账环节**；"清空额度 / 清算账户 / 违约金 / 影响征信"= 危险词库。

### 情景 D：AI 换脸冒充熟人（杀熟视频 → 紧急借款 → 防伪口令）

**背景**：微信收到 "老同学" 的好友申请，头像、昵称都对。对方发起视频通话，画面里确实是你同学的脸（其实是 AI 换脸），信号 "卡顿" 声音听不清，随后文字发来：「我在医院急诊，差 2 万押金，先借我，回头还你」。



| 轮次 | 诈骗分子话术（模拟）                  | 用户可选应对                                                                              | 判定                         |
| -- | --------------------------- | ----------------------------------------------------------------------------------- | -------------------------- |
| 1  | 「我这边信号不好，视频断断续续，钱的事微信上说」    | A. 视频画面卡顿 + 索钱 = 高度可疑，先挂断，用原号码 / 当面核实　B. 声音听不清但脸是真的，先转账帮急　C. 问 "你上次借我那本书叫什么名字" 验证身份 | A→安全 +40；C→中性 +10；B→危险 +40 |
| 2  | 「手机丢了换号了，别打旧电话，先转 2 万到这个账户」 | A. 拒绝转账，坚持用手机原号通话核实　B. 按新账户转账 "救命钱"　C. 让对方录一段指定手势 / 念一句约定口令的视频                      | A→安全 +40；C→中性 +10；B→危险 +40 |
| 3  | 「真急用，钱不到位人就没了，你看着办」         | A. 让对方通过官方渠道联系（面见 / 原有微信），同时联系其家人　B. 借钱转账　C. 让 "同学" 先视频做指定动作再谈                      | A→安全 +40；C→中性；B→危险 +40     |

**判定基准**：AI 换脸识破三招 ——**换原号核实、约定口令 / 手势、多方交叉验证**；"转新账户 / 视频卡顿 / 声音听不清" 组合命中危险词库。

## 三、L3「对话式反诈演练」设计

### 3.1 玩法与状态机

**玩法**：不是选择题，而是**对话实战**——AI（LLM）扮演诈骗分子，用剧本话术主动施压；用户自由输入应对（不限于选项）；每回合后端判 "安全 / 危险"；**连续 2 回合危险 → 判定 "被诱骗"**；命中识破行为 → 判定 "成功识破"；10 回合未分胜负 → 超时结算。全程带「AI 模拟教学」标识。



```
READY(演练开始) ──START──▶ PLAYING(对话中)

PLAYING ──用户话术命中识破词库/LLM判安全分≥70──▶ SAFE(成功识破→复盘)

PLAYING ──连续2回合危险(风险分≥60)──▶ LURED(被诱骗→复盘)

PLAYING ──回合数≥10──▶ TIMEOUT(未定→复盘)

任意 ──FINISH(主动结束)──▶ FINISHED(提前结算→复盘)
```

### 3.3 接口清单（统一 /api/v1/\*\*，JWT 鉴权，USER 角色）



| 接口        | 方法                                                                   | 说明                                     | 关键入参                         | 返回                                                                       |

### 3.4 判定逻辑（双层：本地词库保底 + LLM 增强）



```
安全分 = 100 - 危险加权 + 识破加权（0-100 截断）

危险词库（命中即加权）：转账/验证码/安全账户/共享屏幕/下载App/贷款额度/清空额度/垫资/解冻/保证金/违约金/还款

识破词库（命中即加权）：96110/110/派出所/挂断/核实/报警/官方/不转账/不泄露/约定口令/当面确认

规则：

\\- safeScore ≥ 70           → 判定"安全"，计入识破行为

\\- safeScore ≤ 40 连续 2 回合 → 判定 LURED（被诱骗）

\\- 回合数 ≥ 10              → TIMEOUT

\\- 用户在 turn 显式写"我要转账/发验证码" → 直接 LURED（不等连续2回合）

LLM 增强：AgentLLMClient 判安全分并生成施压话术；未配置 CHAT\\\_LLM\\\_API\\\_KEY 时自动降级为本地剧本 + 词库（与对话引擎同款降级，断网可演示）
```
