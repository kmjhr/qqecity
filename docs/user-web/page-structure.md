# 用户端页面结构

本文档基于需求清单中的页面描述，整理用户前端的页面结构、路由路径与菜单对应关系。

## 页面总览

用户端面向青年用户（租客/借款人/消费者），覆盖三大场景 + 金融安全 + 消息中心。

## 路由-页面-功能对应表

| 路由路径 | 页面组件 | 菜单/入口 | 主要功能 | 对应模块 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| `/login` | Login | 登录页 | 手机号+密码登录、注册入口 | 用户与授权 | P0 |
| `/register` | Register | 登录页→注册 | 填写手机号、姓名、证件号、人群类型注册 | 用户与授权 | P0 |
| `/` | Home | 首页（默认页） | 模块入口卡片、快捷演示、个人信息入口 | 公共支撑 | P0 |
| `/guarantee` | Guarantee | 安居保函 | 保函申请、保函列表、状态流转查看 | 模块1 安居金融风控 | P0 |
| `/guarantee/apply` | GuaranteeApply | 保函页→申请 | 填写房东信息、租赁要素、押金金额，上传材料 | 模块1 安居金融风控 | P0 |
| `/guarantee/:id` | GuaranteeDetail | 保函列表→详情 | 保函详情、缴费、状态查看 | 模块1 安居金融风控 | P0 |
| `/loan` | Loan | 青创e贷 | 预审入口、授信展示、额度查询 | 模块2 轻创业智能授信 | P0 |
| `/loan/precheck` | LoanPrecheck | 贷款页→预审 | 提交创业计划与人群资质，获取额度区间 | 模块2 轻创业智能授信 | P0 |
| `/loan/withdraw` | LoanWithdraw | 贷款页→提款 | 受托支付模拟、指定商户 | 模块2 轻创业智能授信 | P0 |

| `/budget/save` | BudgetSave | 预算页→转储蓄 | 月底结余一键转入心愿储蓄 | 模块4 碎片消费治理 | P0 |
| `/bookkeeping` | Bookkeeping | 经营记账 | AI 记账记录、现金流报表（占位） | 模块3 创业经营赋能 | P0（占位） |
| `/safety` | Safety | 金融安全 | 反诈教学内容、骗局甄别输入 | 模块5 青年金融安全 | P0 |

| `/profile` | Profile | 首页→个人中心 | 当前用户信息、退出登录 | 用户与授权 | P0 |

## 页面布局

- **主框架**：`MainLayout.vue`（顶部导航 + 侧边菜单 + 内容区）
- **登录页**：独立布局，无侧边菜单
- **路由守卫**：未登录访问业务页自动重定向 `/login`

## 侧边菜单结构

```
首页
───
场景一·安居
  安居保函
场景二·创业
  青创e贷
  经营记账
场景三·消费
  预算消费
───
金融安全
消息中心
个人中心
```

## 演示主链路页面流

```
登录/注册 → 首页 → 安居保函（申请→详情→缴费→已开立）
→ 青创e贷（预审→额度→受托支付）
→ 预算消费（设置预算→查看扣减→触发提醒→转储蓄）
→ 金融安全（反诈教学→骗局甄别）
→ 消息中心（查看提醒）
```
