# 管理端页面结构

本文档基于需求清单中银行运营岗（人工复核）等管理角色的功能，整理管理端页面结构。

## 角色说明

管理端面向**银行运营岗**与**系统管理员**，负责保函索赔复核、贷款审核、用户管理、消息管理等后台运营工作。

## 路由-页面-功能对应表

| 路由路径 | 页面 | 菜单 | 主要功能 | 对应模块 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| `/login` | Login | 登录页 | 管理员账号登录 | 公共支撑 | P0 |
| `/` | Dashboard | 首页/仪表盘 | 数据概览、用户统计、业务量统计 | 公共支撑 | P1 |
| `/user` | UserList | 用户管理 | 用户列表、用户详情、用户状态管理 | 用户与授权 | P1 |
| `/guarantee` | GuaranteeList | 保函管理 | 保函列表、状态查询、人工复核入口 | 模块1 安居金融风控 | P0 |
| `/guarantee/review` | GuaranteeReview | 保函管理→人工复核 | AI 复审存疑的保函人工审核 | 模块1 安居金融风控 | P0 |
| `/guarantee/claim` | ClaimList | 保函管理→索赔管理 | 违约索赔列表、AI 初审结果、人工复核 | 模块1 安居金融风控 | P1 |
| `/loan` | LoanList | 贷款管理 | 贷款申请列表、授信记录查询 | 模块2 轻创业智能授信 | P1 |
| `/loan/review` | LoanReview | 贷款管理→审核 | 贷款人工审核 | 模块2 轻创业智能授信 | P1 |
| `/message` | MessageManage | 消息管理 | 消息发送、消息模板管理、推送记录 | 消息中心 | P1 |
| `/safety` | SafetyManage | 安全管理 | 反诈内容管理、骗局规则配置 | 模块5 青年金融安全 | P2 |
| `/system` | SystemConfig | 系统配置 | 参数配置、字典管理 | 系统 | P2 |

## 页面布局

- **主框架**：侧边导航 + 顶部栏（管理员信息、退出）
- **表格为主**：各管理页以列表/表格 + 筛选 + 详情弹窗为主

## 侧边菜单结构

```
仪表盘
───
用户管理
───
保函管理
  保函列表
  人工复核
  索赔管理
贷款管理
  贷款列表
  贷款审核
───
消息管理
安全管理
系统配置
```

## 说明

- MVP 阶段管理端优先保障**保函人工复核**功能（演示中规则命中时状态流转至"人工复核"）
- 其他管理功能（用户管理、贷款审核、消息管理等）可根据演示需要逐步实现
- 管理端与用户端共用同一套后端 API，通过角色权限区分可访问的接口
